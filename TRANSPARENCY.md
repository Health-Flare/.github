## Practice

- Updated quarterly, or whenever a material change happens (a new cost
  category, a payout to a contributor, a big one-time expense).
- Every entry is a real transaction, not an estimate. Round to the nearest
  dollar; no need for cent-level precision in the public summary.
- Categories stay consistent quarter to quarter so totals are comparable.
- Link the update from the main FUNDING.md and from a pinned/release note
  where sponsors will see it (e.g. a GitHub Discussion or repo release).
